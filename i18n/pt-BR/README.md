# Guia de Estudos DP-800 — Português Brasileiro

Esta é a tradução em Português Brasileiro do DP-800 Study Guide. O conteúdo em
inglês fora de `i18n/` é canônico; cada arquivo traduzido preserva o mesmo
caminho relativo para facilitar comparações e atualizações.

## Conteúdo disponível

- [Teoria](./certification/dp-800-overview.md)
- [Parte 0 — Fundamentos do SQL Server](./certification/00-fundamentals/fundamentals.md) (pré-requisito)
- [Laboratórios práticos SQL](./practice/labs/)

## Status de sincronização

As traduções são mantidas em paralelo ao conteúdo canônico. Quando um arquivo
em inglês for atualizado, a versão pt-BR correspondente deve ser revisada e
sincronizada em um commit posterior.

## Convenções

- A prosa, os comentários SQL e as orientações de execução são traduzidos.
- Sintaxe SQL, nomes de produtos, identificadores, URLs e mensagens de erro
  permanecem em inglês quando a tradução alteraria o comportamento técnico.
- Os links internos permanecem no locale pt-BR quando o arquivo equivalente
  existir; caso contrário, apontam para o original em inglês com a indicação
  *English only*.
